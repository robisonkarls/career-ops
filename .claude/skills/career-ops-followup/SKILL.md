# career-ops-followup — Follow-Up Cadence Tracker

Flag overdue applications and generate polished follow-up message drafts.

## Instructions

Load context:
- Read `modes/followup.md`
- Read `data/applications.md` (if exists)
- Read `data/follow-ups.md` (if exists)

You can also run:
```
node followup-cadence.mjs
```

Then execute the followup mode as defined in `modes/followup.md`.
Flag applications past their follow-up window and generate ready-to-send message drafts.
